# 扩散模型
- 传统算法的问题：
    - 无法很好拟合多模态的动作分布(例如面对障碍物向左绕过去和向右绕过去都是有效解，但是如果取均值便会成为向前冲的错误动作)
    - 传统RL出现Q值过度估计/误差累积的问题
- 解决方法：
    - 将策略建模为逆向去噪的过程
    - 先输入初始的纯高斯噪音，去噪网络会在状态s的引导下一步一步排除不合理的动作，去噪的采样能明确的收敛到一个左边或者是右边的动作，不会是中间值
- 扩散策略是直接生成未来的动作序列，而不会预测状态
- 去噪迭代：如果模型要输出未来16帧的电机角度变化，它会先完全乱猜一个随机的噪音轨迹，然后在当前的状态st的引导下化10/20步的去噪迭代，将噪音变为一条平滑，符合物理规律的动作序列

# DDPO（Denoising Diffusion Policy Optimization）模型
- 我的每一个动作的表达形式就是下一个状态，把状态和动作融合在了一起
- 利用RL微调扩散模型的算法
- 原有模型的问题：
    - 很多非微分的模型无法通过监督学习进行反馈和反向传播
    - 传统奖励加权回归的方法会让图片失去多样性和畸变

## 核心思路：
- 将T步去噪采样的轨迹映射为强化学习中的决策序列
- 本质上就是把经典的PPO算法适用在扩散模型之中，两者的核心思想一样但是在MDP建模和网络框架中有区别
- DDPO：
    - 使用高位的连续空间来预测下一阶段的图像(图像是指)
    - 奖励信号极为稀疏，但是PPO算法的奖励一般很多
    - 不使用Critic网络，直接用Batch内的奖励均值作为baseline
    - 使用类似于高斯分布的算法来实现
