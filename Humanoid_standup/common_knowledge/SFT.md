# RL中的SFT是怎么训练的：
- 机器人中的SFT有点类似于模仿学习，让模型先记住人类示范的轨迹然后保存权重给模型
- 当使用SFT初始化完成后就可以直接使用奖励函数来对机器人进行进一步的训练

# 不同的模型对于SFT：

| 训练范式 | 代表算法 | 是否需要 SFT？ | 核心原因 |
| :--- | :--- | :---: | :--- |
| **传统环境 RL** | DQN, PPO (游戏/控制), SAC | **不需要** | 环境自带明确标量奖励（分数值），探索空间小，可从零自主进化。 |
| **语言模型 RLHF** | PPO (LLM), Direct RL | **必须** | 语言动作空间巨大（数十万 Token），无天然奖励，必须靠 SFT 限制探索范围。 |
| **隐式偏好对齐** | DPO, IPO, SimPO，GRPO | **必须** | 依赖 $\pi_{sft}$ 作为参考基准（Anchor），防止模型偏离人类语言分布。 |
