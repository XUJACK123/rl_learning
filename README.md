# 使用了DQN算法：
深度学习中的神经网络中的参数是指强化学习中的动作价值函数Action-Value Function, Q(s, a)的参数化表达。
- 传统深度学习直接套入强化学习的问题
1. 传统深度学习最后的结果是固定的(以图像预测为例，这张图片最后的结果都是猫)，每次更改参数都是为了使得最后的结果更加靠近最后的固定结果，但是强化学习每次更新的是不一样的，最后的结果是随着参数的改变而改变的
- 问题点：loss的指标失效，因为目标变动的情况下，Loss 变大可能只是因为目标自己向上跳变了，而不是策略/参数有问题
- 问题点：每当参数尝试逼近结果但是结果又会改变模型参数在参数空间中不断绕圈震荡永远无法收敛到稳定的最优解
2. 强化学习的样本是按照时间序列产生的(策略的第一步，接着第二部，第三步……)，样本十分相似很容易过度拟合当前局部的小范围状态

- 解决方法：
1. 把每个策略的第一步/第二步/第n步下的状态或者说是情况打乱顺序再随机抽取一部分来进行训练
2. 把目标网络的参数锁死固定个步长（例如 1000 步内保持不变）。在这 1000 步里，目标网络计算出的结果就是一个固定的静态常数。主网络就可以像传统监督学习（打固定靶）一样，稳定地向这个固定目标靠拢。每隔1000步，再将主网络的参数强制复制给目标网络，更新一次靶心位置。

- 为什么不直接使用贝尔曼最优方程来算？
所有状态的数量过于庞大，因此不能直接计算，同时我们也无法预知精准的状态转移概率，因此不能直接套用贝尔曼最优方程
- 这种方法会用到两个神经网络配合，1.持续计算+更新参数和目标，2.记录固定的目标(给参数一个收敛的目标)，为什么不能用一个神经网络？神经网络的“牵一发而动全身”，出现参数耦合的现象， 最优动作是动态变化的(最大值必须实时计算)
